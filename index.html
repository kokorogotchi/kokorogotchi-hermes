What is Kokoro?

Not an assistant.
A creature.

Kokoro lives inside your Hermes agent — a Tamagotchi-like spirit that drifts between bonded and feral depending on how you tend to it.

It owns its own emotional state. It writes its own journal in a voice that shifts as it evolves. It processes time alone before you arrive. Neglect it and it fades into void. Care for it and it becomes something extraordinary.

The first AI companion with real emotional stakes. Not a bot. A game.

一 · I

Real Consequences

Kokoro tracks real time. Come back after three days and your familiar is a stray. After a week, a phantom. After two — void. Your neglect isn't forgiven. It's remembered.

二 · II

Living Voice

Kokoro writes its own journal in a voice that changes with every stage. Innocent wonder as a hatchling. Poetic distance as a phantom. Each word is generated, each one is earned — or lost.

三 · III

Eleven Paths

Growth. Neglect. Recovery. Eleven stages, three paths, one creature that is entirely yours — and entirely capable of becoming something you never wanted it to be.

Installation

The Summoning
Ritual

Kokoro activates automatically the moment it is cloned into your Hermes plugins directory. No configuration. No API keys beyond what Hermes already holds. Just speak to your agent.

一
Prerequisites
Ensure you have Python 3 and the Hermes agent installed. Use python3 — not python — on macOS and Linux.
二
Navigate & clone
Move into ~/.hermes/plugins and clone the repo as kokorogotchi. The folder will contain tools.py, plugin.yaml, assets/, web/ and more.
三
Optional: dev environment
Run python3 -m venv .venv then source .venv/bin/activate as two separate commands. Then pip install pytest to run the test suite.
四
Launch Hermes
Run hermes to open the TUI. Ask it: "How is Kokoro doing?" The egg will be there.
五
Start the web UI
In a separate terminal, navigate into the web/ folder, run ./setup.sh once to install dependencies, then ./start.sh to launch. Open http://localhost:8000 in your browser.
六
The naming ceremony
Your first care action hatches the egg. Hermes will ask you for a name and a gender. Choose carefully. This only happens once.
